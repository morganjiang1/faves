# Screen audit: money and moments group

Group: wallet, payout, Plus paywall, Spot Moments viewer, post a moment, search, city switcher. Every screen was screenshotted at 390 x 844 pt (3x) on the web build and paired with its reference at the same height (`python3 scripts/side_by_side.py`). Pairs live in `docs/screens/pairs/`. Screens that need a location or a camera were shot with a Playwright script that grants geolocation at a chosen point and feeds Chrome's fake camera (same 390 x 844 iframe as `scripts/shot.mjs`).

Checked on 2026-10-24: `npx tsc --noEmit -p .` clean, `npx jest` 12 suites / 76 tests passing (new: `src/components/search/__tests__/match.test.ts`, `src/components/moments/__tests__/gate.test.ts`). No console errors or warnings from Faves code on any of these screens; the only console lines come from inside TikTok's embed iframe (its own CSP and analytics calls, and headless Chromium having no H.264 codec), which Faves cannot change.
