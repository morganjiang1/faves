Checked 2026-10-24 on the web build at 390 x 844 pt (3x), each screenshot next to its reference at the same point scale (our screenshot cropped to the reference's height in points where the reference is a partial screen). Pins 3 and 5 of the featured day overlap at the default zoom (they are 300 m apart).
